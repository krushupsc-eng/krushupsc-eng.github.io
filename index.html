SEQUEX is an AI-first creative studio from Chhatrapati Sambhajinagar, Maharashtra, focused on new app and game development. Using the latest AI tools, we design mobile puzzle games, Android apps, coloring books and storybooks for children and adults, and digital tools that help urban local bodies work faster and more transparently.

What we build

Four focus areas, one goal: work that is simple to use, delightful, and genuinely useful.

🎮

Mobile Games

Clean, offline-friendly puzzle games that are easy to learn and hard to put down, starting with Sequex: Number Puzzle.

📱

Android Apps

Lightweight apps for the Google Play Store, built for everyday users and designed to work well on any phone.

📚

Books & KDP Designs

Coloring books for kids and adults, illustrated storybooks, and print-ready interiors and covers designed for Amazon KDP.

🏛️

Tools for Urban Local Bodies

Digital and AI-assisted tools for municipal corporations and councils, such as field surveys, photo documentation and reporting, built with a deep understanding of how civic programmes run on the ground.

How we build

Built with the latest AI tools

AI is at the core of how we work. We keep up with the newest AI models and tools, and use them at every stage, so a small team can ship high-quality games, apps and books quickly. Every result is reviewed and refined by people before it ships.

⚡

AI-assisted development

Modern AI coding assistants help us design, write, test and improve our game and app code faster.

🎨

AI-assisted design

Always up to date
